Pipes Básicos

Este es un ejemplo de cómo usar las pipes básicas de Angular.

Lowercase pipe
{{ nameUpper() | lowercase }}
Valor original: {{ nameUpper() }}
Uppercase pipe
{{ nameLower() | uppercase }}
Valor original: {{ nameLower() }}
Titlecase pipe
{{ fullName() | titlecase }}
Valor original: {{ fullName() }}
Date pipe
{{ customDate() | date }}
Valor original: {{ customDate() }}
Date pipe long
{{ customDate() | date : "long" }}
Valor original: {{ customDate() }}
Date pipe short
{{ customDate() | date : "short" }}
Valor original: {{ customDate() }}
Date pipe medium
{{ customDate() | date : "medium" }}
Valor original: {{ customDate() }}
Date pipe dd/MM/yyyy
{{ customDate() | date : "dd/MM/yyyy" }}
Valor original: {{ customDate() }}
Date pipe HH:mm:ss
{{ customDate() | date : "HH:mm:ss" }}
Valor original: {{ customDate() }}
Date pipe EEEE d, MMMM
{{ customDate() | date : "EEEE d, MMMM " }}

Locale Actual: {{ localeSelected() }}
