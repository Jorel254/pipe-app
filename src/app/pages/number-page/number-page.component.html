Pipes Numéricos

Este es un ejemplo de cómo usar las pipes numéricas de Angular.

Number pipe 1.2-4
{{ totalVentas() | number:'1.2-4' }}
Valor original: {{ totalVentas()}}
Number pipe 1.2-2
{{ totalVentas() | number:'1.2-2' }}
Valor original: {{ totalVentas()}}
Number pipe 1.0-0
{{ totalVentas() | number:'1.0-0' }}
Valor original: {{ totalVentas()}}
Currency pipe EUR
{{ totalVentas() | currency:'EUR' }}
Valor original: {{ totalVentas()}}
Currency pipe USD
{{ totalVentas() | currency:'USD' }}
Valor original: {{ totalVentas()}}
Currency pipe CAD
{{ totalVentas() | currency:'CAD' }}
Valor original: {{ totalVentas()}}
Percent pipe
{{ porcentaje() | percent }}
Valor original: {{ porcentaje()}}
Percent pipe 2.2-2
{{ porcentaje() | percent:'2.2-2' }}
Valor original: {{ porcentaje()}}
Percent pipe 2.2-4
{{ porcentaje() | percent:'2.2-4' }}
Valor original: {{ porcentaje()}}
